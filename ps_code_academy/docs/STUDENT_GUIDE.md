# RP Code Academy - Student Guide

## Starting
1. Double-click **RP Code Academy** on the desktop (or Start menu). Your web browser opens the app. No internet is needed.
2. The first time, type your name. This creates your profile on this computer.
3. Keep the small black window/tray process running while you learn; close the browser tab and the app when you are finished.

## Learning path
- **Lessons**: choose a module, then a lesson. Read it, press **Mark lesson as done**, then do the exercises below it.
- **Exercises**: write code in the editor.
  - **Run** runs your code (use the optional input box if your program uses `input()`).
  - **Check** tests your code against hidden-style test cases. Your output must match exactly.
  - **Hint** shows one hint at a time.
  - **Solution** unlocks after 3 unsuccessful checks (or after you pass).
  - **Reset** restores the starting code.
- **Quizzes**: one per module. Pass mark is 70%. Retake as often as you like.
- **Projects**: five bigger programs that use many skills.
- **Playground**: try anything; nothing is graded.
- **Achievements** and **My Progress** show how far you have come.

## Tips
- The editor does not insert tabs: type **4 spaces** for indentation.
- Outputs are compared exactly, so check spelling, spaces and capital letters.
- Do not print extra prompts like `Enter a number:` unless the exercise asks.
- Programs stop after 5 seconds, so watch for endless loops.
- Programs can only use files in their own temporary folder. Internet and other programs are blocked.

## If something goes wrong
Tell your teacher. Your progress is saved after every Check and backed up daily.
