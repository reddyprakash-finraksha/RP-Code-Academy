# Scope, *args and Recursion
* Variables made inside a function are **local**.
* `*args` collects extra arguments into a tuple.
* A **recursive** function calls itself, and needs a base case to stop.

```python
def total(*nums):
    return sum(nums)

def countdown(n):
    if n == 0:
        return
    print(n)
    countdown(n - 1)
```
