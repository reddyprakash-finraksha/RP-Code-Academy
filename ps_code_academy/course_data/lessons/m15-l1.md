# Classes and Objects
A **class** is a blueprint; an **object** is one thing built from it.

```python
class Dog:
    def __init__(self, name):
        self.name = name
    def speak(self):
        return f"{self.name} says Woof!"

d = Dog("Rex")
print(d.speak())
```
`__init__` runs when the object is created. `self` is the object itself.
