# String Methods
Strings have useful methods:
```python
"I like Java".replace("Java", "Python")
"banana".count("a")          # 3
"  hi  ".strip()             # "hi"
"red,green".split(",")       # ['red', 'green']
"-".join(["a", "b"])         # "a-b"
```
Strings are **immutable**: methods return a new string.
