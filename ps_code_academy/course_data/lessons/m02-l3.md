# Type Conversion
Convert values with `int()`, `float()`, `str()` and `bool()`:

```python
int("25")      # 25
float("3.5")   # 3.5
str(100)       # "100"
int(7.9)       # 7  (cuts off the decimal)
bool(0)        # False   (0, "" and empty collections are False)
```
You cannot add a string and a number directly: `"5" + 5` is an error. Convert first.
